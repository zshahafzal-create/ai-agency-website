# ZeroWait AI website

Static GitHub Pages website for ZeroWait AI.

## Files

- `index.html` — homepage, solutions, demonstration placeholder, and consultation booking.
- `styles.css` — layout, mobile styling, uniform electric blue-violet headings, and animated blue-purple outlines on booking buttons and the Calendly frame.
- `main.js` — accessible mobile navigation and copyright year.
- `assets/zerowait-circuit-hero.webp` — optimized hero artwork.
- `assets/zerowait-circuit-hero.png` — full-resolution source/social sharing image.
- `assets/favicon.svg` — simple circuit-themed favicon.
- `terms.html` and `privacy.html` — website information pages, for owner review.

## Integrations

- **Calendly:** The single booking embed and fallback link point to
  https://calendly.com/zainabshahafzal/free-ai-consultation.
- **Chatwoot:** The existing website inbox connection from the latest GitHub
  version has been carried over into `main.js` and loads on all three pages.
  Verify that the website chat launcher and messages still work after publishing.
  Never paste a private API key into the public website source.

## Before publishing

1. Review the privacy and terms pages, including the contact method, actual
   providers, retention practices, and applicable legal requirements.
2. Test the restored website chat widget on the live website.
3. Confirm that the Calendly event is active and the booking timezone is right.
4. Test the homepage and the two legal pages on mobile and desktop.

This is a static website. No paid hosting subscription or build step is required.
