HOW TO PREVIEW ON WINDOWS
1. Right-click the downloaded ZIP and choose Extract All.
2. Open the newly extracted folder.
3. Make sure index.html, styles.css, main.js, and the assets folder are together.
4. Double-click index.html (not the ZIP itself).
5. If you see plain text and blue underlined links, styles.css is not alongside the HTML file. Re-extract the entire ZIP into one folder.

HOW TO PUBLISH
Upload the CONTENTS of this folder to the root of your existing GitHub Pages repository.
Retain the folder structure, especially assets/.
Do not upload just index.html or just the ZIP as the website's home page.
